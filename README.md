# Uitleg
## Verbinding maken
### Handmatig
- Verbinding maken met de sensor gaat via WiFi. Verbind met het netwerk "QualityLuchtSensor™". Je gaat dan automatisch naar een de pagina waar je de data kan zien.
### Via de Connect-App
- Je kan ook verbinding maken via de Connect-App. Deze staat op https://roanh47.github.io/QualityLuchtSensor/ en kan worden geinstalleerd als web-app (PWA) op je thuisscherm
